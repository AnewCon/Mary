# 网格交易实验室 V1.0

网站左侧及手机版的「网格实验室」打开回测工作台。预测历史仍可从工作台顶部查看。策略库、自动执行权限和既有模拟账本不参与这条链路。

## 使用

1. 输入 Binance USDⓈ-M 永续合约交易对，例如 AKEUSDT，选择北京时间日期区间及周期。
2. 选择「绘制网格箱体」在蜡烛图点击两条边界。切回平移工具，可拖动上下限，或在参数区精确输入。「拉直线」可在图上按住拖动，画出任意角度的线段。按 Shift 拖动可画水平线。线段按时间和价格保存，支持选中删除、撤销／重做和锁定。线段用于绘图分析，网格回测使用箱体的固定上下限。
3. 设置网格、资金与风险，点击「开始模拟」。优先下载 1m 数据，超过 7 天或详细数据不可用时明确标注较粗粒度。可拖动进度、单步和调整倍率。
4. 播放完成后查看账户权益、回撤与持仓明细，导出完整 JSON。已保存方案保存在当前浏览器的 IndexedDB，包含行情快照、绘图、配置与已生成的回放结果。

## 数据与成交假设

- Worker 通过 VPS 已有的只读行情中继访问 `GET /fapi/v1/exchangeInfo`、`GET /fapi/v1/klines` 和 `GET /fapi/v1/fundingRate`。请求按区间分页，排除未收盘数据，发现缺口则提示错误。读取当前合约过滤器，不回填历史过滤器变化。
- 回测先生成时间有序的成交及资金快照，播放从同一份快照读取。限价进出按网格价估算 Maker 成交，市价退出采用可调 Taker 费及滑点。滑点为比例模型，模拟不复现订单簿排队、盘口深度、部分成交或交易所资金费精确时序。
- 同根冲突优先检查硬止损、估计强平、亏损／回撤与突破。交易价 K 线是近似风控输入，未使用交易所标记价全历史、实际维持保证金阶梯、强平费用或交叉账户其他仓位。持仓在当根开仓时不会在本根同时计入目标成交。资金费在对应 K 线起始对既有仓位计入，使用公开资金费时钟与可得标记价。
- 保留持仓模式可继续退出，是否停止开新仓由单独开关决定。暂停待重画在突破点结清该轮，通过「以当前权益开始下一箱体」开启下一轮。本轮结束若仍有持仓，报告保留未实现盈亏。
- 中性网格以回放起点价格分隔多空网格，起点所在格跳过，任一时刻保持单向净持仓。价格及数量使用交易所步进，保证金、最小数量与名义门槛会约束开仓。
- 查看完整区间再画箱体属于事后回放。实测不是提前预测，也不触发 Binance 实盘或 Demo 订单。

静态插画由内置生图工具分别生成，网站文件为 `public/grid-lab-hero.webp`、`public/grid-lab-empty.webp` 和 `public/grid-lab-report.webp`。
