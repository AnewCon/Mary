# QuantOS 设计留存

保存位置：桌面 IV。版本：2026-11-10 V1.1。

核心任务：查看账户、持仓、同步状态，进行有确认步骤的模拟盘部分平仓；独立 API Access 为后续 GPT 集成准备。

视觉：黑曜石底色、薄边框、翡翠绿强调色；左侧固定工作空间导航，账户权益主视觉，四项账户指标，持仓表格，AI协作入口；手机端横向导航和可滚动持仓表格。金融数据缺失显示破折号，不使用装饰性假行情或收益图。

五页：Dashboard / Positions / AI Activity / API Access / Settings。管理员登录后进入工作区。Key 全文仅创建时展示，复制使用浏览器剪贴板；撤销与轮换独立操作。平仓弹窗显示比例滑动条、25/50/75/100%快捷比例、最新合约/方向/可平张数、精度向下取整后的下单数量及预计盈亏。

前后端分离：Pages 承载前端与同源 API 代理；独立 Worker 处理认证、Secrets、同步和 Cron；D1 保存快照、AI记录、密钥哈希、会话、限流和审计。数据库不存欧意 Secret。

交易所：用户最后提供欧意模拟账户，因此覆盖原构想中的 Binance。所有交易所请求强制 x-simulated-trading:1，读取账户与永续持仓，并允许提交模拟盘市价减仓单。现支持欧意模拟盘部分平仓，实盘仍禁用。

每分钟 Cron 同步；页面60秒轮询，手动刷新强制读取交易所。失败保留上次成功快照和原时间戳。超过120秒显示过期。每次同步持有数据库原子短租约，避免并发刷新；同步日志保留最近1440条。

缺少 Passphrase 时允许部署，但账户数据明确为空。待配置三项欧意凭证后，使用立即刷新验证。平台密钥可提前创建并测试 AI 数据读写。

首版不含：实盘平仓、自动交易引擎、历史成交已实现盈亏、保护订单止盈止损读取、MCP服务本体。图像模型生成轨道网格主视觉；当前无GIF模型，网页使用减少动态效果偏好兼容的CSS动画。

V1.1：平仓弹窗使用原子十进制数量计算与只减仓语义，操作记录保存实际订单号、请求张数、累计成交量及剩余仓位。请求超时后只查询，不自动重下。每个持仓的未终结操作通过D1唯一索引互斥。
