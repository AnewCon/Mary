# 币安 USDⓈ-M 模拟盘

QuantOS 的「币安模拟盘」页面读取交易所模拟账户的 USDT 余额、保证金和当前合约仓位。账户快照存在 D1 的 `binance_demo_snapshot` 设置中。Worker 每分钟同步，页面每分钟读取缓存，也可点「立即刷新」请求交易所。同步失败会保留最近的快照，超过两分钟标记为待更新。

## 启用条件

1. 在目标 Worker 确认访问 `https://demo-fapi.binance.com/fapi/v1/time` 能收到 HTTP 200 和 `serverTime`。2026 年 11 月 11 日，QuantOS 的 Cloudflare 独立测试 Worker 收到 HTTP 403。
2. 创建币安模拟盘 HMAC 密钥，在目标 Worker 的 Variables and Secrets 中分别保存为 `BINANCE_DEMO_API_KEY` 和 `BINANCE_DEMO_SECRET_KEY`。
3. 设置 Worker 环境变量 `BINANCE_DEMO_ENABLED=true`。网站重新登录后，导航会出现「币安模拟盘」。用「立即刷新」核对余额和仓位。

## 模拟交易

先在目标数据库应用 `0007_binance_demo.sql`，再设置 `BINANCE_DEMO_TRADING_ENABLED=true`。管理员登录后可市价开仓、按比例市价平仓和调整杠杆。平仓使用最新仓位与合约步长计算数量，单向持仓模式发送只减仓订单。

操作在 D1 中保存独立请求编号。同一编号重复提交不会再次发送。交易所响应超时时，可用编号查询原订单；杠杆修改结果不明时请在币安模拟盘核对当前倍数。
