## 收益定义

累计净收益 = 已实现交易盈亏 + 手续费/返佣 + 资金费。

- 正数手续费为返佣，负数手续费为支出，保留欧意符号。
- 资金费采用账单 pnl 字段，缺失时才使用余额变化，不再把它与成交中的收益重复相加。
- 普通交易、强平与自动减仓类型的 pnl/fee 纳入对应币种统计。
- 充值、提现、内部划转、浮动盈亏不计入净收益。不同币种分开显示，不直接相加。
- 收益金额使用十进制整数运算累加，接口返回十进制字符串；显示层才格式化小数。
- 统计对象是 SWAP 永续合约账户。首次回溯欧意接口可提供的最近90天，后续持续累计到D1；不声称覆盖账户终身历史。
- 账单与成交历史各自保留原始交易所记录、billId与时间戳。收益只由账单计算，成交历史用于追溯细节。
- 分页每次100条、断点保存在数据库，Cron每分钟继续回溯并同步新记录。重叠时间窗口通过billId去重。
- 首次回溯或近期增量分页未完成时显示“已导入部分”；失败保留原成功时间和旧数据。历史记录页面每次显示50条，支持继续读取更早记录。
- 收益曲线按 UTC 自然日累计；历史表时间按浏览器时区显示。

## 新接口

- GET /api/performance：read权限；币种分组的累计净收益、已实现盈亏、手续费、资金费、UTC累计曲线、统计范围、完整状态与错误。
- GET /api/history?kind=fills：read权限；历史成交。
- GET /api/history?kind=bills：read权限；原始账户流水。
- GET /api/history?kind=fills&cursor=...：继续读取更早记录。
- POST /api/performance/sync：write权限；回溯及增量同步，每分钟最多6次。

所有接口使用原有单用户会话或平台Bearer密钥。原有平仓接口仍仅登录会话可用，不开放给read/write密钥。
