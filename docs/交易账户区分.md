# QuantOS 交易账户

- 欧意 OKX 模拟账户继续由欧意 API 同步，单独计算收益。
- 币安虚拟账户由网站保存订单。Chat 可使用 `quantos_paper_list_orders` 跨会话读取，使用 `quantos_paper_write_order` 设置初始资金、模拟开仓、更新估值或平仓。写入需要现有 QuantOS 写入权限，不会向任何交易所发单。
- 币安 USDⓈ-M 模拟盘 API 是另外的未来接入区。

新聊天先读取订单，按币安行情插件实际返回的报价和时间逐笔更新。网站不定时重算。每个变更使用一个 UUID，失败重试用原 UUID；只有 COMMITTED 表示保存成功。资金单位 USDT，按 1 倍模拟，不计手续费、资金费或滑点；平仓结算整笔。初始资金由用户指定且不与欧意本金共用。
