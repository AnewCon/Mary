# QuantOS 交易账户

| 账户 | 数据来源 | 更新时机 |
| --- | --- | --- |
| 欧意 OKX 模拟账户 | 原有 OKX API | 维持既有同步、持仓、收益账本及模拟交易功能 |
| 币安虚拟账户 · Chat 账本 | Chat 使用插件读取行情，在聊天中维护虚拟成交 | Chat 复盘时计算；复制摘要到网站，点击保存才发布快照 |
| 币安 USDⓈ-M 模拟盘 · API 接入 | 币安交易所模拟 API | 后端接入并启用后才读取 |

Chat 账本可用以下指令开始复盘：

> 请用币安插件拉取市场数据。按本聊天中币安虚拟账户的初始资金、模拟成交及手续费，计算余额、持仓、已实现和未实现盈亏；列出行情时间和本次复盘时间。只更新本聊天中的币安虚拟账本，不调用 QuantOS 的欧意账户工具。输出一段可以粘贴到网站的摘要。

建议在同一个聊天中维护该账本；换聊天时带上原始成交记录。摘要保存到 QuantOS 日志（标记 `quantos:binance:chat-paper-review:v1`），供其他设备登录后查看。网站读取最近 100 条日志中的最新对应快照。摘要只是记录，不会执行订单或进入任何账户的余额和盈亏计算。

将来部署 VPS 时，参考[币安模拟盘接入](币安模拟盘接入.md)。网站使用现有同源 `/api/binance-demo/*` 接口；VPS 需通过 QuantOS 的受认证后端接入，网站不会接收或保存币安密钥。先验证只读的账户和持仓，再决定是否启用模拟交易。
