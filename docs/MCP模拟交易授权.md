# 手机 ChatGPT 模拟交易授权 · 2026-11-10

按用户明确要求，本次将 QuantOS 私人交易计划连接器设为“允许所有操作”，并为其专用平台密钥增加 demo_trade 权限。其他插件及全局默认权限没有改变。Sites 保持仅本人访问。

## 可用功能

基础6个读取和交易计划工具保留，新增9个模拟交易工具：读取合约规格/持仓/标记价，读取普通及保护挂单，市价或限价开多/开空，按比例市价平仓，设置止盈止损，修改或取消保护单，取消普通挂单，查询操作结果。

所有交易所请求强制使用 OKX 模拟盘头。只支持永续合约，数量单位为合约张数；不调整杠杆，不提供实盘、划转或提现接口。普通 read/write 密钥不能交易。双开关 DEMO_TRADING_ENABLED 和 MCP_DEMO_TRADING_ENABLED 均开启才可使用连接器交易工具。

交易操作必须携带 UUID requestId，同一请求重试沿用该值。服务端先写审计记录，再提交订单；响应不明确时查询原订单，避免盲目重发。开仓方向与已有净持仓相反时拒绝自动反手。平仓和保护单从最新持仓计算，净持仓使用 reduceOnly。

止盈止损以标记价触发、市价执行；同时设置时提交 OCO，100% 保护跟随仓位。已有保护单时不静默覆盖，使用修改或明确取消。交易所可能拒绝订单，应以操作查询及挂单状态确认结果。

## 验证与使用

45项隔离测试通过，覆盖权限、数量/价格精度、平多平空、保护单、改单撤单与响应丢失去重。线上只读验证工具列表已增至15，持仓读取正常；未代用户提交测试交易。

Sites 更新后，手机新建聊天并重新选择 QuantOS 连接器获取新工具。下单指令应明确合约、方向、数量、订单类型及限价（若适用）；保护指令应明确仓位、比例与触发价格。实际下单验收等待用户给出具体交易参数。
